# MediTalk

MediTalk is a React web application that connects doctors and patients. Users can register as a doctor or a patient, browse doctors by specialty, read recent studies shared by doctors, and take part in health discussions.

Live site: https://meditalk-pro.vercel.app

## Pages

- Home
- Doctors 
- Studies
- Discussions
- About
- Contact
- Register
- 
## Technologies

- React
- React Router
- MUI icons

## Setup

1. Clone the repository.
2. Install the packages:

```
npm install
npm install @mui/icons-material @mui/material @emotion/react @emotion/styled
```

3. Start the app:

```
npm start
```

The app opens at http://localhost:3000.
